## 🧩 Repository Structure
Each folder in `/projects` contains:
- `README.md` — project overview, architecture, and steps  
- `infrastructure/` — IaC templates (CloudFormation)  
- `pipeline/` — build/deploy YAML files  
- `src/` — example application code  
- `screenshots/` — architecture or AWS console images
